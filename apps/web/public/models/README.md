# Model files

`public/models/v1/` holds the model the app runs on-device:

```
manifest.json   class list, preprocessing, version (generated by ml/scripts/make_manifest.py)
model.onnx      MobileNetV3-Small, 6.1 MB
```

The current model is **0.4.0-experimental**: trained on public photos, no field validation, no "not a leaf" class, uncalibrated confidence. The app labels results accordingly. Details: `ml/reports/model-v4/README.md`.

To ship a new model: put `model.onnx` here, regenerate `manifest.json` with `python ml/scripts/make_manifest.py --reports <reports folder>`, then run `pnpm content:validate` (class ids must match `content/diseases/*.json`). Without a manifest the app falls back to clearly labelled demo mode.
